# Optional LinkedIn launch angle | Lab 02

**Premise:** A matching name is not necessarily the same identity.

My second financial crime AI governance experiment explores a deceptively simple question. What happens when a screening model is exceptionally confident, yet the names it compares belong to different people?

The Sanctions AI Governance Lab uses invented customers and a fictional reference registry to test exact matching, fuzzy name similarity and an explainable logistic regression model. Visitors can inspect the evidence behind candidate alerts, challenge conflicting identifiers, compare false positives and missed cases, then record a simulated human review decision.

The lesson is not that a model can establish someone's sanctions status. It cannot. The point is that technology must provide transparent evidence, and that human reviewers must understand what the system knows, what it assumes and what remains unresolved.

This is an educational prototype, not an official sanctions screening service. The development process involved AI coding and drafting assistance, with methodology, model validation and limitations disclosed in the repository.
